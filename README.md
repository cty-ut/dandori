**業務担当者が読めて、AI が書けて、会社が安心して動かせる** ── 日本の業務自動化のためのプログラミング言語です。

```
「入金明細.csv」を読み込んで、入金とする。
「請求一覧.xlsx」の「10月」シートを読み込んで、請求とする。

消込の名義は、入金の振込依頼人と請求のフリガナとする。
消込の金額は、入金の金額と請求の請求金額とする。
消込の手数料は、880円までとする。

入金を請求に消し込んで、結果とする。
結果から判定が「要確認」のものを絞り込んで、「出力/消込結果.xlsx」の「要確認」シートに書き出す。
```

プログラムは日本語の文そのものです。語順は日本語のとおり（〜を〜する）で、引数は助詞で決まります。

> **開発中です（v0.0.1）。** 文法や機能はまだ変わります。本番の業務にはまだ使わないでください。

## なぜ段取りか

日本の会社の多くの業務は Excel と CSV で回っています。VBA や Python で自動化すると、**書いた人にしか読めない**プログラムが残ります。AI に書かせても、それが正しいかを業務担当者が確かめられません。

段取りは次の三つを同時に満たすことを目指しています。

| | どうやって |
|---|---|
| **業務担当者が読める** | 日本語の文法。経理の言葉（消し込む、締め、前倒し）がそのまま動詞になる |
| **AI が書ける** | 文法が小さく、検査が厳しい。AI は検査に通るまで自分で直す |
| **会社が安心して動かせる** | 使うファイルの宣言、試し実行、実行記録、承認、予定どおりの実行 |

## できること

- **表の操作**：読み込む、絞り込む、合計する、数える、並べる、書き出す
- **CSV と Excel**：CSV は UTF-8 と Shift_JIS を自動判定。Excel はシートを指定でき、見出しの前の表題行を飛ばす。書き出すと本物の数・日付になり、複数のシートを 1 つのファイルにまとめられる
- **金額**：`1,000円`、`¥1,000`、`△500` を読める。端数は `切り捨てる` などで明示（Excel と同じ丸め）
- **日付**：和暦（`令和8年10月31日`、`R8.10.31`）、`期日+3営業日`、`期日+1か月`、`月末`
- **日本の業務知識**：銀行営業日（内閣府の祝日表）、会社の休日、支払条件（`月末締め翌月末払い`）、消費税率、名義の表記ゆれ（`ｶ)ﾔﾏﾀﾞｼﾖｳｼﾞ` → `ヤマダショウジ`）
- **入金消込**：完全一致、手数料差引、まとめ入金、名義対応表。判定と理由つき
- **安心して動かす仕組み**
  - `この処理が使うもの`：読み書きするファイルを宣言。宣言にないことはできない
  - `dandori 説明`：実行せずに、読み書きするファイルを表示
  - `dandori 試し`：実行するが書き出さない
  - 途中でエラーになったら何も書き出さない
  - 実行記録（データは記録せず、ファイルの指紋だけ）
- **AI 助手**（`dandori-ai`）：日本語の要望からプログラムを書く。決められない業務ルールは自分で決めずに「確認事項」として残す
- **基盤**（`dandori-platform`）：予定どおりの実行（`毎月25日（休日なら前営業日） 9時`）、承認（プログラムと規則のファイル）、実行履歴

## はじめる

Python 3.11 以上が必要です。

```bash
pip install "dandori[ai] @ git+https://github.com/cty-ut/dandori.git"
```

```bash
dandori 実行 -c "100と200を足して表示する。"
# 300
```

例は [examples/](examples/) にあります。

```bash
git clone https://github.com/cty-ut/dandori.git
cd dandori
dandori 説明 examples/入金消込/入金消込.dandori
dandori 試し examples/入金消込/入金消込.dandori --今日 2026年11月2日
```

```
判定      理由                                          振込依頼人        金額  請求番号  差額
自動消込  名義が一致、手数料差引（440円）               ｶ)ﾔﾏﾀﾞｼﾖｳｼﾞ     109120  A001      -440円
要確認    名義は一致するが、金額が一致しません（候補：220,000円）  ｶ)ﾀｶﾊｼｹﾝｾﾂ  200000
入金不明  名義・金額とも一致する請求がありません        ﾀﾅｶ ﾀﾛｳ          50000
未入金    対応する入金がありません（支払期日を過ぎています）                      A004
…
（試し実行：ファイルは書き出していません）
```

### AI に書かせる

```bash
export DEEPSEEK_API_KEY=...        # または ANTHROPIC_API_KEY、OPENAI_API_KEY
dandori-ai 作る "「明細.csv」の金額を取引先ごとに合計して表示して" --出力 集計.dandori --提供元 deepseek
```

AI はプログラムを書くだけで、実行はしません。CSV・Excel の中身は既定では送らず、列名・型・行数・空欄の数（Excel はシート名も）だけを送ります。

### 予定どおりに動かす

```
実行の予定は、「毎月25日（休日なら前営業日） 9時」とする。
```

```bash
dandori-platform 登録 入金消込/入金消込.dandori
dandori-platform 承認 入金消込 --承認者 田中
dandori-platform 起動
```

承認の後にプログラムや規則のファイル（名義対応表など）が一文字でも変わると、承認し直すまで実行しません。

## ロードマップ

| 方向 | 内容 |
|---|---|
| 実際のデータ | Excel の読み書き（済）→ **既存の Excel への転記** → 総合振込ファイル（全銀形式） |
| 文書 | 利用者向けの手引き（チュートリアル、言語リファレンス）を GitHub Pages で公開 |
| 業務の領域 | 支払処理、請求書の作成、勤怠の集計、仕訳 |
| 書く体験 | VS Code 拡張（色分け、エラー表示）、コメント、整形 |
| AI 助手 | 評価の拡充、Claude・OpenAI での評価 |
| 基盤 | 失敗の通知、Web 画面、途中で承認を待つ処理 |
| 配布 | pip なしで使える Windows 版、PyPI |
| 信頼性 | ランダムな入力での検査、大きな表の性能 |
