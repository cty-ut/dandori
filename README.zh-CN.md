# 段取り（Dandori）

[日本語](README.md) | **简体中文**

[![CI](https://github.com/cty-ut/dandori/actions/workflows/ci.yml/badge.svg)](https://github.com/cty-ut/dandori/actions/workflows/ci.yml)

**业务人员读得懂、AI 写得出、企业敢运行**：面向日本业务自动化的编程语言。

```
「入金明細.csv」を読み込んで、入金とする。
「請求一覧.xlsx」の「10月」シートを読み込んで、請求とする。

消込の名義は、入金の振込依頼人と請求のフリガナとする。
消込の金額は、入金の金額と請求の請求金額とする。
消込の手数料は、880円までとする。

入金を請求に消し込んで、結果とする。
結果から判定が「要確認」のものを絞り込んで、「出力/消込結果.xlsx」の「要確認」シートに書き出す。
```

程序就是日语句子：语序与日语相同（〜を〜する），参数由助词决定。

> **开发中（v0.0.1）。** 语法和功能还会变化，请不要用于正式业务。

## 为什么做段取り

日本公司的大量业务靠 Excel 和 CSV 运转。用 VBA、Python 自动化之后，留下的是**只有写的人才读得懂**的程序；让 AI 来写，业务人员也无法确认它是否正确。

段取り要同时做到三点：

| | 怎么做 |
|---|---|
| **业务人员读得懂** | 日语语法；财务的用语（消し込む、締め、前倒し）直接就是动词 |
| **AI 写得出** | 语法小、检查严格；AI 根据检查结果自己修正，直到通过 |
| **企业敢运行** | 声明使用的文件、试运行、执行日志、批准、按时运行 |

## 能做什么

- **表格操作**：读取、筛选、合计、计数、排序、写出
- **CSV 与 Excel**：CSV 自动识别 UTF-8 与 Shift_JIS；Excel 可以指定表（シート）、自动跳过表头前的标题行；写出真正的数和日期，多张表可以放进一个文件
- **金额**：能读 `1,000円`、`¥1,000`、`△500`；端数必须用 `切り捨てる` 等明确处理（与 Excel 相同的舍入）
- **日期**：和暦（`令和8年10月31日`、`R8.10.31`）、`期日+3営業日`、`期日+1か月`、`月末`
- **日本的业务知识**：银行营业日（内阁府的祝日表）、公司休日、支付条件（`月末締め翌月末払い`）、消费税率、名义的写法差异（`ｶ)ﾔﾏﾀﾞｼﾖｳｼﾞ` → `ヤマダショウジ`）
- **入金消込**：完全一致、手续费差额、合并付款、名义对应表；附判定和理由
- **让企业敢运行的机制**
  - `この処理が使うもの`：声明读写的文件，声明之外的事做不了
  - `dandori 説明`：不执行，只列出会读写的文件
  - `dandori 試し`：执行但不写出
  - 中途出错时什么都不写出
  - 执行日志（不记录数据，只记录文件的指纹）
- **AI 助手**（`dandori-ai`）：根据日语需求写程序；定不下来的业务规则不自己决定，留作"確認事項"
- **平台**（`dandori-platform`）：按时运行（`毎月25日（休日なら前営業日） 9時`）、批准（程序和规则文件）、运行历史

## 开始使用

需要 Python 3.11 以上。

```bash
pip install "dandori[ai] @ git+https://github.com/cty-ut/dandori.git"
dandori 実行 -c "100と200を足して表示する。"
# 300
```

范例在 [examples/](examples/)：

```bash
git clone https://github.com/cty-ut/dandori.git
cd dandori
dandori 説明 examples/入金消込/入金消込.dandori
dandori 試し examples/入金消込/入金消込.dandori --今日 2026年11月2日
```

### 让 AI 来写

```bash
export DEEPSEEK_API_KEY=...        # 或 ANTHROPIC_API_KEY、OPENAI_API_KEY
dandori-ai 作る "「明細.csv」の金額を取引先ごとに合計して表示して" --出力 集計.dandori --提供元 deepseek
```

AI 只写程序，不执行。默认不发送 CSV、Excel 的内容，只发送列名、类型、行数和空欄数（Excel 还有表名）。

### 按时运行

```
実行の予定は、「毎月25日（休日なら前営業日） 9時」とする。
```

```bash
dandori-platform 登録 入金消込/入金消込.dandori
dandori-platform 承認 入金消込 --承認者 田中
dandori-platform 起動
```

批准之后，程序或规则文件（名義対応表等）哪怕改了一个字，在重新批准之前都不会运行。

## 路线图

| 方向 | 内容 |
|---|---|
| 真实数据 | Excel 读写（已完成）→ **往已有的 Excel 中转记** → 総合振込文件（全銀格式） |
| 文档 | 面向用户的手册（教程、语言参考），用 GitHub Pages 发布 |
| 业务领域 | 支付处理、请求书制作、考勤汇总、会计分录 |
| 写程序的体验 | VS Code 扩展（高亮、错误提示）、注释、格式化 |
| AI 助手 | 扩充评测，用 Claude、OpenAI 评测 |
| 平台 | 失败通知、网页界面、中途等待批准 |
| 交付 | 不需要 pip 的 Windows 版、PyPI |
| 可靠性 | 随机输入测试、大表的性能 |
