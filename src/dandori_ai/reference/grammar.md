# 段取り（Dandori）言語リファレンス

段取りは、日本の業務自動化のためのプログラミング言語です。プログラムは日本語の文で書き、業務担当者がそのまま読めることを最優先にしています。

## 1. 文の基本

- 文は必ず「。」で終わる。一つの文は複数行にまたがってよい
- 手順は「〜を…する」の形。**引数は助詞で決まり、順番は自由**：`10から3を引く。` と `3を10から引く。` は同じ
- 「て形」で手順をつなぐと、前の手順の結果が次の手順の空いている引数に入る：
  `100と200を足して表示する。` → 300
- 「、」はて形の後にだけ置ける：`2と3を掛けて、10から引いて表示する。`
- 文の最後の動詞は辞書形（〜する、〜す）。途中の動詞はて形（〜して）
- `それ` は直前の手順の結果。`その金額` は「それの金額」（直前の結果の表の金額の列）
- 値：数 `100`、`3.14`、`1,000`、`100万`；金額 `100円`、`1,000円`、`100万円`、`¥1,000`；文字列 `「こんにちは」`；日付 `2026年10月31日`、`令和8年10月31日`、`今日`；`10%`（＝0.1）
- 計算：`+ - × ÷`（`* /` も可）、`( )`。掛け算・割り算が先
- 並び：`100と200`

## 2. 名前（変数）

- 代入：`税率は0.1とする。`
- 手順の結果に名前をつける：`100と200を足して、合計とする。`（文の最後に「名前とする」）
- **名前は漢字・カタカナ・英数字だけ。ひらがなは使えない**：`売上`（○）`売り上げ`（×）。公用文の書き方（売上、支払、振込、見積）にする
- どうしてもひらがなを含む名前を使うときは、プログラムの最初に `用語：売り上げ、お客様。` と書く
- 名前の型は変えられない（数の名前に文字列を入れられない）。再代入はできる

## 3. 条件

```
もし合計が100万円以上ならば、
  区分は「大口」とする。
そうでなく合計が10万円以上ならば、
  区分は「中口」とする。
そうでなければ、
  区分は「小口」とする。
ここまで。
```

- 比較：`AがB以上` `AがB以下` `AがB未満` `AがBを超える` `AがB`（等しい）`AがBでない`。記号 `>= <= < > = <>` も可
- **日付の比較は** `以前` `以降` `より前` `より後`（`以上`などは日付に使えない）
- `かつ` `または`（一つの条件に両方を混ぜない）
- 「ならば」だけ（「なら」は不可）。ブロックは必ず `ここまで。` で閉じる
- すべての分岐で決めた名前だけが、`ここまで。` の後で使える
- 休日の判定：`もし期日が休日ならば`、`期日が営業日ならば`

## 4. 繰り返し

```
3回繰り返して、
  …
ここまで。

月を1から12まで繰り返して、
  …
ここまで。

明細のそれぞれについて、
  もし金額が100000以上ならば、
    取引先を表示する。
  ここまで。
ここまで。
```

- 「それぞれについて」の中では、**列名をそのまま書くと今の行の値**
- `繰り返しをやめる。`、`次に進む。`
- 繰り返しの中では書き出せない
- **表の操作で書けることは繰り返しで書かない**（絞り込む、合計するなどを使う）

## 5. 表（CSV）

```
「明細.csv」を読み込んで、明細とする。
明細から金額が10000以上のものを絞り込んで、その金額を取引先ごとに合計して、表示する。
```

- ファイル名は「」で直接書く（変数は使えない）。プログラムのフォルダの中だけ
- `明細の金額`：列。列名にひらがな等があるときは `明細の「支払い期日」`
- 条件の主語の「」は列名：`明細から「支払い期日」が空欄のものを絞り込む。`
- `〜のもの`（名詞・以上・以下・未満の後）と `〜もの`（を超える・でないの後）
- 表の操作の中では、名前は列名として扱われる。**列と同じ名前の変数を作らない**
- 空欄は0ではない。計算に空欄が含まれるとエラー。`金額が空欄でないもの` で除くか、`明細の金額の空欄を0で埋める`。**どちらにするかは業務のルール**（平均の値が変わる）なので確認する
- 書き出し：`集計を「出力/集計.csv」に書き出す。`（新規作成。すでにあるとエラー）／上書き：`「集計.csv」を集計で上書きする。`

### Excel

```
「請求一覧.xlsx」の「10月」シートを読み込んで、請求とする。
結果から判定が「要確認」のものを絞り込んで、「出力/消込結果.xlsx」の「要確認」シートに書き出す。
```

- `「ファイル」の「シート名」シート`。**シートが複数あるときは必ず書く**（inspect_file でシート名を確かめる）。1 枚だけなら省略できる
- 見出しの前の表題行は自動で飛ばす
- 同じ .xlsx の別のシートに書き出すと、1 つのファイルにまとまる。シート名を書かなければファイル名（「集計.xlsx」→「集計」）
- 上書きはファイル全体を置き換える（ほかのシートは残らない）。.xls、.xlsm には書き出せない

## 6. 金額と日付

- 金額と数は混ぜて計算できる。1円未満の端数がある金額は表示・書き出しできない → `切り捨てる` `四捨五入する` `切り上げる`
- 税：`金額×取引日の標準税率を切り捨てて、消費税とする。`
- 日付 ± 数（日数）、`期日+3営業日`、`期日+1か月`、`期日-今日`（日数）
- `営業日` は**銀行の営業日**（土日・祝日・12月31日〜1月3日が休み）。会社の休日で数えるときは `暦の会社休日は「会社休日.csv」とする。` と書いて `会社営業日` を使う
- 日付の属性：`期日の月末` `期日の曜日` `期日の年度` `期日の和暦` など
- 支払日：`請求日を「月末締め翌月末払い」で支払日にして、前倒しして、支払予定日とする。`
- 名寄せ用の文字列：`「ｶ)ﾔﾏﾀﾞｼﾖｳｼﾞ」を整える`

## 7. 設定文と権限宣言

```
この処理が使うもの：
  読み込み：「入金明細.csv」、「請求一覧.csv」
  書き出し：「出力」フォルダ
ここまで。

消込の名義は、入金の振込依頼人と請求のフリガナとする。
消込の金額は、入金の金額と請求の請求金額とする。
入金を請求に消し込んで、結果とする。
```

- 「この処理が使うもの」はプログラムの最初（用語の後）。読み込み・書き出し（新規作成）・上書きを分けて書く
- 設定文：`〈名前空間〉の〈設定〉は、〈値〉とする。` 一番外側にだけ書ける
- 消込の結果は表：判定（自動消込・要確認・入金不明・未入金）、理由、入金側の列、請求側の列、差額
- `消込の手数料は、880円までとする。` は任意の設定。**許容額は会社ごとに違う業務のルールで、標準値はない**。書かなければ手数料を差し引いた入金は「要確認」になる

## 8. よくある間違い

| 間違い | 正しい書き方 |
|---|---|
| `売り上げは0とする。` | `売上は0とする。`（または `用語：売り上げ。`） |
| `もし合計が0なら、` | `もし合計が0ならば、` |
| `3回繰り返す。` | `3回繰り返して、…ここまで。` |
| `期日が今日以上` | `期日が今日以降` |
| `100万円×10%を表示する。`（端数が出る場合） | `…を切り捨てて表示する。` |
| 条件の中で動詞を使う（`〜を整えたものが`） | 先に `〜を整えて、名前とする。` で名前をつける |
| `として` | 使えない。名前は文末の `〜とする` で |
